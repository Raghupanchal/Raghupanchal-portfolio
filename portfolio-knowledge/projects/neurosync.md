# NeuroSync - AI Interview Intelligence & Proctoring

## Project Overview
**NeuroSync** is an AI-powered remote technical interview intelligence and automated proctoring platform designed to streamline online candidate evaluations and skill assessment.

## Key Capabilities & Features
1. **Automated Eye-Tracking**: Tracks candidate focus, distraction patterns, and confidence in real time.
2. **Screen Activity Auditing**: Monitors browser tab switching, code copy-pasting, and proctoring integrity.
3. **Speech & Audio Analysis**: Evaluates voice pauses, filler words, and communication clarity.
4. **Real-Time Candidate Readiness Scoring**: Generates multi-dimensional performance indexes for technical recruiters.

## Technical Stack
- **AI & Analysis**: Python, OpenCV, Audio Processing Pipelines, Machine Learning models
- **Web & Backend**: React, TypeScript, Django REST Framework, PostgreSQL, WebSockets
