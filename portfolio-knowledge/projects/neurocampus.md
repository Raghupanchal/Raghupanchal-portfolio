# NeuroCampus AI - Smart Campus Automation Platform

## Project Overview
**NeuroCampus** is an AI-driven smart campus automation platform engineered to modernize campus administration using Computer Vision and Machine Learning.

## Key Capabilities & Features
1. **Facial Recognition Attendance**: Deep learning facial recognition with anti-spoofing and liveness detection for automated classroom attendance logging.
2. **BLE Proximity Verification**: Bluetooth Low Energy beacon integration to prevent proxy attendance and ensure physical presence.
3. **Automated CO-PO Attainment**: Automatic calculation of Course Outcomes (CO) and Program Outcomes (PO) mapping in compliance with NBA and NAAC accreditation standards.
4. **Campus Safety Analytics**: Real-time crowd monitoring and abnormal activity detection using OpenCV and neural networks.

## Technical Stack
- **AI / ML & Vision**: Python, OpenCV, TensorFlow, Keras, dlib
- **Backend & Real-Time**: Django REST Framework, PostgreSQL, Redis, WebSockets
- **Frontend**: React, TypeScript, Tailwind CSS
